使用说明

  • 点字幕：跳到这一句，同时可以直接修改；改完自动保存。点时间：只跳转。
  • 空格：播放 / 暂停（不在编辑时）　Ctrl + K：任何时候播放 / 暂停
  • Ctrl + ← / →：后退 / 前进 3 秒　Ctrl + ↑ / ↓：上一句 / 下一句
  • Enter / Esc：结束编辑　Ctrl + S：立即保存　Ctrl + Z：撤销拆分、合并、删除和 AI 校对
  • 鼠标移到字幕上，右侧有工具：对齐到当前时间、在光标处拆分、与下一句合并、删除。
  • 术语表：在「设置 → 老师与术语表」里给每位老师建一份；在顶栏选择这个视频是哪位老师的课。也可以在媒体库的文件夹上绑定老师，里面的视频会自动用这位老师。
  • 存疑句：AI 校对时拿不准、读起来不通的句子会用橙色标出，不会乱改。点字幕栏上方的「存疑」按钮逐句跳过去，会单句循环播放方便回听；改好后点「已确认」。
  • 画面：AI 区的「画面」页点「找关键帧」，软件会挑出课件、板书、老师手绘这类画面，让 AI 写成画面记录（照录课件文字和板书、分清哪些是老师现场画的、抄下画面上的字幕）。AI 校对、课程重点和对话都会参考画面记录；课程重点里可以插图，剪藏时图片会复制到笔记旁边的 image 文件夹。看到重要画面也可以点「截取当前画面」。
  • 查漏补缺：对照完整字幕，把课程重点漏掉的内容补进对应小节，并显示字幕被引用到的比例。
  • 剪藏：笔记上半部分是课程重点，下半部分是完整带时间戳的字幕，可以直接用来蒸馏。

换电脑：导出 / 导入设置

导出成一个文件，在新电脑的猛人字幕里导入，就能直接用原来的设置、各家 API 密钥、ChatGPT 登录、老师和术语表。

缓存和日志放在哪里

默认放在软件所在的文件夹里，文件夹名就写着「可随时删除」，不占 C 盘。更改后重启软件生效。

软件出问题时（报错、卡住、关不掉），日志里会记下原因。把日志文件夹里的 app.log 发给 Claude 就能查。日志不包含 API Key。设置、老师档案和媒体库很小，放在下面「设置」那个文件夹里。
